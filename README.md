# KnowledgeCoach

KnowledgeCoach یک پلتفرم دانش‌محور برای مدیریت دانش، هدایت یادگیری، تعامل هوشمند با محتوا، ارزیابی یادگیری، و تحلیل پیشرفت کاربران است.

هدف این محصول این است که دانش خام و پراکنده را به یک تجربه یادگیری ساختاریافته، تعاملی، قابل سنجش و قابل تحلیل تبدیل کند. در این سیستم، محتوا از منابع مختلف مانند متن، لینک، فایل و PDF وارد می‌شود، ingest و برای retrieval آماده می‌شود، از روی آن مسیرهای یادگیری ساخته می‌شود، روی آن chat و Q&A انجام می‌شود، و در نهایت assessmentهای مبتنی بر همان دانش برای کاربران تولید و تصحیح می‌شوند.

KnowledgeCoach فقط برای دانش سازمانی طراحی نشده است. این محصول می‌تواند هم در فضای سازمانی و تیمی استفاده شود و هم در سناریوهای عمومی، تخصصی، حرفه‌ای و فردی. یک متخصص مستقل نیز می‌تواند منابع آموزشی خود را وارد کند، مسیر یادگیری بسازد، آن را منتشر کند، و دیگران از آن استفاده کنند.

## قابلیت‌های اصلی

- ورود و مدیریت محتوا از متن، لینک، فایل و PDF
- ingest و آماده‌سازی محتوا برای retrieval و AI usage
- ساخت مسیرهای یادگیری مرحله‌محور
- استفاده مجدد از محتوا در چند مسیر و چند مرحله
- تعامل هوشمند با محتوا از طریق chat و Q&A
- assessment در سطح مرحله و مسیر
- تولید آزمون اختصاصی برای هر کاربر
- تصحیح خودکار پاسخ‌های تستی و تشریحی
- تحلیل زمان یادگیری و pace کاربر
- مقایسه وضعیت کاربر با expectation و با جامعه کاربران
- نمایش سیگنال‌های مربوط به سؤال‌های پرتکرار و نقاط ابهام رایج
